# Manejo BionD para Soja

Esta skill contém os protocolos de manejo biológico para a cultura da soja.

## Quando Usar

Quando o cliente mencionar soja, ferrugem, oídio, mancha-alvo, ou perguntar sobre manejo para soja.

## Níveis de Manejo

### Manejo Essencial
- Tratamento de sementes (TS)
- Foco no estabelecimento inicial
- Produtos: Sollum Rs, Sollum Az, Sollum Amy

### Manejo Soja Forte
- TS + Aplicação no sulco
- Foco em nutrição e raízes
- Adiciona: Sollum Bs, Sollum Bm

### Manejo BionD
- TS + Sulco + Foliar
- Proteção biológica completa
- Adiciona: Protec Bp, Protec Bsf, Sollum Trc

## Doenças-alvo dos Biofungicidas

- Míldio
- Ferrugem asiática da soja
- Mancha-alvo
