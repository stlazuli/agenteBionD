# Manejo BionD para Feijão Mungo Preto

Esta skill contém os protocolos de manejo biológico para a cultura do feijão mungo preto.

## Quando Usar

Quando o cliente mencionar feijão mungo preto, mungo, ou perguntar sobre manejo para esta cultura.

## Níveis de Manejo

### Manejo Essencial
- Tratamento de sementes
- Estímulo ao crescimento radicular
- Produtos: Amy, Trc

### Manejo Raiz Forte
- Solubilização de fósforo
- Maior vigor vegetativo
- Produto: Bm

### Manejo BionD
- Proteção biológica completa
- Bioinseticida e controle de fitopatógenos
